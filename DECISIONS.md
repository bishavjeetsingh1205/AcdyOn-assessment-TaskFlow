# Decisions

## 1. Why this approach?

I chose to build the landing page using plain HTML, CSS, and JavaScript instead of using a framework. The main reason was to keep the project simple and focus on the required responsive layout and user experience.

I considered using React, but for a single landing page it would have added unnecessary setup and complexity. Plain HTML, CSS, and JavaScript were sufficient for the requirements.

## 2. Trade-off

Because of the limited development time, I focused on completing the main sections and responsive layout instead of adding more advanced interactions or functionality.

With more time, I would improve the visual design, add more interactive product demonstrations, and perform more extensive testing across different browsers and devices.

## 3. AI tools

I used AI tools to help with the initial structure and implementation of the HTML, CSS, and JavaScript.

After generating the code, I reviewed and tested the implementation myself. I made sure that I understood the main HTML structure, CSS layout and responsive rules, and JavaScript used for the scroll animation and button interaction.1
